# Foundry Tools

> [!TIP]
> **Interactive version:** Explore [Foundry Tools at Ignite 2026](https://aka.ms/foundrytoolsignite26) for a guided tour of Foundry Tools.

Explore Foundry Tools for connecting AI agents to business context and specialized AI capabilities.

## Topics covered

- **Tool Catalog and Toolboxes:** Discover tools, connect remote MCP servers, and securely connect agents to real-world tools.
- **Azure Speech:** Speech recognition, voice generation, real-time voice agents, and speech translation.
- **Azure Content Understanding:** Extract structured insights from multimodal content using prebuilt and custom analyzers.
- **Azure AI Document Intelligence:** Extract document structure and data, and compare approaches to document processing.
- **Azure Translator and Azure Language:** Translation, PII detection and redaction, and intent routing.

- [Open Microsoft Foundry](https://ai.azure.com/) to explore the platform and start building.
