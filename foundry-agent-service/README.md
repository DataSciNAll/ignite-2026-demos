## Demos and hands-on learning

- [Watch: New Microsoft Copilot Harness](https://www.youtube.com/watch?v=4vCbQMUVV-I) - Microsoft Mechanics video on more power, token efficiency, and control for agents in Foundry.
- [Learn: AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners) - A course to get started building AI agents.
- [Explore: Microsoft Foundry samples](https://github.com/microsoft-foundry/foundry-samples) - Official documentation samples, notebooks, and code examples.
- [Voice Agent In Foundry Agent Service](https://foundry-voice-agent.jollysea-6ef865d5.canadacentral.azurecontainerapps.io/) - A demo app for a voice agent

## Start building

- [Open Microsoft Foundry](https://ai.azure.com/) to explore the platform and start building.
- [Read the Agent Service documentation](https://learn.microsoft.com/en-us/azure/foundry/agents/overview) for capabilities and guidance.

Samples may require an Azure subscription and deployed resources. Review each sample's prerequisites and clean up resources when finished to avoid ongoing charges.
