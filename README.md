# Microsoft Foundry Ignite 2026 Demos

A collection of demo assets showcasing Microsoft Foundry capabilities presented at Ignite 2026. Each folder covers a specific topic area with video walkthroughs, presentations, Ignite sessions, and documentation.

## Topics

- [FinOps on Microsoft Foundry](finops-on-microsoft-foundry/)
- [Foundry Agent Service](foundry-agent-service/)
- [Foundry IQ](foundry-iq/)
- [Foundry Tools](foundry-tools/)
- [Foundry Training](foundry-training/)
- [Microsoft Foundry and Agent 365](foundry-and-a365/)
